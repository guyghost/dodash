Phase Review du workflow dodash — suis le skill `dodash-workflow` (phase 2) : rédige `models/$ARGUMENTS.review.md`.

Format : `# Revue — <titre> (date)`, `Verdict : **APPROUVÉ POUR IMPLÉMENTATION LOCALE**` (ou refus motivé), puces argumentées couvrant : pureté de la résolution, effets de bord, respect des invariants, limites acceptées, impact sur les modèles voisins. Une revue d'amendement ou de correction est une nouvelle section datée dans le même fichier.
